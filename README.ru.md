# GRUB Theme Editor by ewenloy

[English](README.md) | **Русский**

Визуальный (WYSIWYG) редактор тем GRUB. Полностью работает в браузере — ничего устанавливать, собирать и запускать не нужно. Открыл `index.html` — и рисуешь.

## Возможности

- **Рисуй тему на холсте** — меню загрузки, прогресс-бар, круговой прогресс, текст, картинки, прямоугольники. Drag & drop, зум, панель свойств, пресеты от 640×480 до 1920×1080.
- **Честный 9-slice.** GRUB принимает рамки только набором отдельных файлов `name_nw.png … name_se.png` — редактор даёт именно эти 9 слотов, а не фальшивое растягивание одной картинки.
- **GRUB-совместимый экспорт PNG.** Любая картинка конвертируется в PNG, а каждый PNG перекодируется в deflate-поток, который понимает собственный (багованный) PNG-декодер GRUB — никакого `error: invalid filter value.` на реальной машине. (См. [нюанс декодера PNG](#примечания) ниже.)
- **Встроенная библиотека иконок ОС** (80+ дистрибутивов/утилит), автоматом по `--class` — с алиасами вроде `macos` → `macosx`.
- **Живое превью** с обратным отсчётом, приближённое к поведению реального GRUB.
- **Импорт и экспорт.** Импорт готовых тем из папки, ZIP, TAR или TAR.GZ; экспорт `theme.txt` или полного ZIP со сниппетом grub.cfg.
- **Файл проекта** (JSON) для сохранения/загрузки; свои шрифты `.pf2`.
- **Языки интерфейса**: английский и русский, переключение одной кнопкой (`lang/*.json` — легко добавить свои).

## Чего это НЕ делает

- Превью — приближение, финальную тему всегда проверяй в QEMU или на реальной машине.
- Не редактирует `grub.cfg`: пункты меню и таймаут задаёт твоя система, редактор рисует только внешний вид.
- Иконки ОС привязываются через `--class` в `grub.cfg` (редактор подсказывает класс для каждой записи).

## Быстрый старт

1. Открой `index.html` в любом современном браузере (или используй хостинг — *добавить ссылку после включения GitHub Pages*).
2. ПКМ по холсту — вставить элемент; справа — свойства.
3. Регулярно **Файл → Сохранить проект** (JSON-файл).
4. **Экспорт ZIP** → папку темы положи в `/boot/grub/themes/your-theme/`, затем в `/etc/default/grub` добавь:
   ```sh
   GRUB_THEME=/boot/grub/themes/your-theme/theme.txt
   ```
   и выполни `sudo update-grub`.

## Примечания

- **Нюанс PNG-декодера GRUB.** В GRUB встроена своя миниатюрная реализация PNG/inflate, у которой построение таблиц Хаффмана ломается на некоторых валидных PNG (например, созданных браузером или ImageMagick) — падение `error: invalid filter value.` и «Press any key to continue…». Редактор при экспорте прозрачно перекодирует каждый PNG в безопасный для GRUB deflate-поток, поэтому темы из него просто работают.
- Undo/redo пока нет. Почаще сохраняйся.

## Участие

Issues и PR приветствуются — особенно полезны баг-репорты с архивом падающей темы.
Чтобы добавить язык интерфейса: положи `lang/<код>.json` (формат как у `lang/en.json`), запусти `node build-lang.js` — готово.
