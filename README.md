# GRUB Theme Editor by ewenloy

WYSIWYG-редактор тем GRUB. Работает в браузере, ничего ставить не надо — открыл `index.html` и рисуешь.

## Умеет

- Рисуешь тему на canvas: меню, прогресс-бар, круговой прогресс, текст, картинки, прямоугольники. Drag&drop, зум, панель свойств.
- Честный 9-slice: GRUB берёт рамки только из набора файлов `name_nw.png … name_se.png` — редактор даёт 9 отдельных слотов, как надо.
- Любую картинку сам перегоняет в PNG (GRUB другие не ест).
- Превью с обратным отсчётом — приближение к реальному GRUB, не 1-в-1.
- Импортирует готовые темы (папка, ZIP, TAR, TAR.GZ), экспортирует `theme.txt` или ZIP со сниппетом grub.cfg.
- Шрифты (.pf2), иконки ОС, сохранение проекта в JSON, пресеты разрешений (640×480 … 1920×1080).

## Чего нет

- Превью неточное — для проверки гоняй тему в QEMU.
- grub.cfg не редактирует: число пунктов меню и таймаут задаёт твой grub.cfg, редактор только рисует вид.
- Иконки ОС привязываются руками через `--class` в grub.cfg.
- Нет undo/redo и тестов.
- Тему ставишь сам: `GRUB_THEME` в `/etc/default/grub` + `sudo update-grub`.

## Как юзать

1. Открыл `index.html` в браузере.
2. ПКМ по холсту — добавить элемент, справа — свойства.
3. Файл → Сохранить проект — чтобы не потерять.
4. Экспорт → положил тему в `/boot/grub/themes/...`, прописал `GRUB_THEME`, `sudo update-grub`.
